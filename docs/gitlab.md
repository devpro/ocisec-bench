# GitLab

## Runner

Runner status can be checked in [Devpro Labs / Runners](https://gitlab.com/groups/devpro-labs/-/runners).

## Variables

Variables are defined in [Devpro Labs / CI/CD Settings](https://gitlab.com/groups/devpro-labs/-/settings/ci_cd#ci-variables).

Key                 | Content
--------------------|----------------------------------
`WIZ_CLIENT_ID`     | Wiz Service Account Client ID
`WIZ_CLIENT_SECRET` | Wiz Service Account Client Secret

> [!IMPORTANT]
> Protected variables can only run on protected branches

## Branch rules

Protected branches are defined in [Devpro Labs / Benchmark / OCI Security Bench / Repository settings](https://gitlab.com/devpro-labs/benchmark/ocisec-bench/-/settings/repository#branch-rules).
